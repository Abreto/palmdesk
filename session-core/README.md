# Session core

PalmDesk maintains this read-only module. It has no Electron, HTTP server or agent execution dependency. `index.mjs` is the bounded reading API; `index.d.mts` defines the data sent to the controller. The desktop integration enables Codex, Claude Code and Claude Desktop local Code reading on macOS and Windows, with explicit opt-in. Session IDs include the provider, and the facade routes each read only to its owning provider. Process discovery is disabled for both adapters.

| Local source | macOS host | Windows host |
| --- | --- | --- |
| Codex | Supported | Supported (native Windows logs) |
| Claude Code | Supported | Supported (native Windows logs) |
| Claude Desktop · Code | Supported | Supported (native local Code logs) |
| Desktop Chat/Cowork, cloud/SSH/WSL retrieval | Unsupported | Unsupported |

Linux hosts do not enable the desktop reader. Native Windows defaults are `%USERPROFILE%\.codex` and `%USERPROFILE%\.claude`; `CODEX_HOME` and `CLAUDE_CONFIG_DIR` override them. WSL homes are not automatically searched. Spaces and non-ASCII paths are supported.

The parser, registry, Markdown renderer and their original tests were imported from [Glassline](https://github.com/Abreto/glassline) commit `63f7d3dd67f723f6f20fe3c91b8e04a725e3bfce`. Their Apache-2.0 [LICENSE](LICENSE) and [NOTICE](NOTICE) are retained. PalmDesk changes include the public reading facade, bounded wire representations, a 32 MiB detail-file limit, incomplete Markdown marker handling and subsequent parser fixes recorded in this repository's history.

The module is maintained in this repository, with no separately deployed Glassline service or separately published package. `src/` uses Node built-ins; `public/timeline-renderers.js` is a separate browser entry and does not import the filesystem adapters. The controller must not import the Node entry at runtime.

Claude Code uses `CLAUDE_CONFIG_DIR || ~/.claude` and discovers root `projects/*/*.jsonl` files, excluding nested subagents. Its summary reads stream the full file up to 32 MiB, retaining compact records to resolve the active parent chain; unchanged summaries are cached. Oversize files remain discoverable as stale entries and their detail reads return an explicit size error. Both providers use the same 32 MiB detail bound, also enforced during reads. Claude titles prefer `custom-title`, then `agent-name`, then `ai-title`, then the first user message. Tool results are matched by `tool_use_id`; Bash is a command and other tools remain tool calls. Thinking, images and internal command wrappers are excluded.

The Claude adapter also reads Desktop's `claude-code-sessions/<account>/<org>/local_<uuid>.json` indexes, bounded to 10 MiB each. On macOS it checks both `~/Library/Application Support/Claude` and `Claude-3p`. Windows checks `%APPDATA%\Claude`, `%LOCALAPPDATA%\Claude-3p` and legacy `%APPDATA%\Claude-3p`, plus `Roaming\Claude`, `Local\Claude-3p` and `Roaming\Claude-3p` under `%LOCALAPPDATA%\Packages\Claude_pzs8sxrjxfjjc\LocalCache`. Missing Windows app-data environment variables fall back to the current user's `AppData\Roaming` and `AppData\Local` directories. `CLAUDE_USER_DATA_DIR` or the `claudeDesktopDataDir` option overrides these roots (an empty option disables Desktop discovery in isolated tests). `cliSessionId` links the index to a global transcript or `<local_uuid or short uuid>/.claude/projects/*/<cliSessionId>.jsonl`. Only fixed paths below these roots are discovered; paths embedded in index data are not followed. Discovery skips symlinked files/directories and Windows junctions within the session trees, including a linked `sessions` or `projects` directory. Desktop SSH/WSL records and Chat/Cowork storage are excluded. Missing transcripts do not create empty sessions.

Desktop entries retain the stable `claude-code:session-file:<cliSessionId>` ID and provider routing, with `source: 'claude-desktop'` for display. Shared copies are deduplicated by transcript ID using the newest transcript; a Desktop title and activity timestamp enrich the selected summary. Metadata and transcript caches are independent, so renames are visible without reparsing unchanged logs. The wire format excludes Desktop IDs, account information, index paths and app configuration. Current format evidence and acceptance limits are in [the integration notes](../docs/GLASSLINE_INTEGRATION.md#claude-desktop-code-读取范围).

Run `pnpm test:session-core` from the repository root. All fixtures are synthetic. Windows defaults, environment overrides, CRLF/partial appends, history, profile deduplication and junctions are covered in `test/windows-discovery.test.mjs`; permission lifecycle tests cover both host platforms. A physical Windows host + phone run for all three sources remains unvalidated; see the [Windows validation record](../docs/smoke-artifacts/windows-session-reading-2026-09-24.md). The imported raw-session and resume-reference parsing helpers are internal; PalmDesk exposes only session listing and paginated reading, with no raw-file, follow-up or command execution endpoint.
