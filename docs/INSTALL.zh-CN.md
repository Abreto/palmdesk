# PalmDesk 安装指南

PalmDesk 是面向 agent-ready workflows（便于衔接 Agent 工作流）的 AI-native 远程控制工具，围绕 AI agent 的使用流程设计：在手机浏览器中发现电脑上的 Agent 应用、阅读本地会话和执行结果，再回到 macOS 或 Windows 上的原窗口继续操作。它目前是实验性预览版，不内置模型，也不会替你执行或编排 Agent。

本文面向第一次安装的用户，按顺序介绍下载、首次打开、授予权限，以及用手机（以 iPhone 为例）完成首次连接。

## 准备

- **Mac**：仅支持 Apple Silicon（M 系列芯片）Mac，需要 macOS 13 Ventura 及以上，不支持 Intel Mac。可在苹果菜单 >“关于本机”中查看，“芯片”一项显示 Apple M 系列即可。预览版在 macOS 15 上构建，macOS 13 和 14 尚未验收。
- **Windows**：Windows 10 1903 及以上或 Windows 11，仅提供 x64 安装包，并需要系统提供可用的 Windows Graphics Capture。
- **手机**：只需要浏览器，不用安装 App。iPhone 推荐使用 Safari。iOS Safari 和微信内置浏览器尚未完成实机验收。
- **网络**：电脑和手机都要能访问 PalmDesk 服务（默认 `https://palmdesk.abreto.icu`）。首次试用建议让两者连接同一个 Wi-Fi，原因见[同一 Wi-Fi 与移动数据](#同一-wi-fi-与移动数据)。
- **Agent 应用（可选）**：想在手机上阅读会话或操作 Agent，先在电脑上安装 Codex、Claude、ChatGPT、Kimi 或 ZCode 等应用；其他普通应用窗口同样可以操作。

Linux 电脑暂时不能作为被控端。

## 下载

1. 在电脑浏览器中打开 [PalmDesk 的 GitHub Releases](https://github.com/Abreto/palmdesk/releases)。目前发布的都是预发布版，列表最上方带“Pre-release”标记的就是最新版本。
2. 展开该版本的“Assets”，下载与电脑对应的安装包。“Source code”是源码压缩包，无需下载。
   - Mac：`PalmDesk-<版本号>-mac-arm64.dmg`
   - Windows：`PalmDesk-<版本号>-windows-x64.exe`
3. （可选）核对安装包：同一处的 `SHA256SUMS.txt` 列出了两个安装包的 SHA256 值。在 Mac 的“终端”或 Windows PowerShell 中计算，结果应与对应文件名那一行相同（不区分大小写）：

   ```bash
   shasum -a 256 ~/Downloads/PalmDesk-*-mac-arm64.dmg
   ```

   ```powershell
   Get-FileHash $HOME\Downloads\PalmDesk-*-windows-x64.exe
   ```

请只从 GitHub Releases 下载安装包。部分网络访问 GitHub 较慢，下载中断时可以重试。

## 在 Mac 上安装并首次打开

Mac 安装包使用自签名证书，没有经过 Apple 公证，所以第一次打开会被 macOS 阻止，需要在“系统设置”中手动允许一次。

1. 双击下载的 `.dmg` 文件，在打开的窗口中把 PalmDesk 拖到“应用程序”文件夹。
   <!-- 截图：DMG 窗口，将 PalmDesk 拖到“应用程序”文件夹 -->
2. 在“访达”边栏中点安装盘旁的推出按钮。不要直接在安装盘里运行 PalmDesk，电脑上也只保留“应用程序”中的这一份，否则启动时可能提示“PalmDesk 应用身份冲突”。
3. 打开“应用程序”文件夹，双击 PalmDesk。macOS 会弹出警告并阻止打开，提示 Apple 无法检查 PalmDesk 是否包含恶意软件，或无法验证开发者。关闭提示即可，不要选择“移到废纸篓”。
   <!-- 截图：macOS 15 及以上首次打开 PalmDesk 时的阻止提示 -->
4. 选取苹果菜单 >“系统设置”，点按边栏中的“隐私与安全性”（macOS 27 中为“隐私与安全”），向下滚动到“安全性”，在 PalmDesk 已被阻止的提示旁点按“仍要打开”。这个按钮在尝试打开 PalmDesk 后约一小时内可用；没有看到时，重复第 3 步后再来。
   <!-- 截图：“隐私与安全性”的“安全性”部分，显示 PalmDesk 已被阻止和“仍要打开”按钮 -->
5. macOS 会再次弹出警告。确认安装包来自上面的 GitHub Releases 后，点按“打开”（部分版本显示为“仍要打开”），再输入 Mac 登录密码或使用触控 ID。
   <!-- 截图：点按“仍要打开”后的确认对话框，以及输入登录密码的提示 -->

完成后，PalmDesk 会保存为安全设置的例外，以后双击即可打开。

macOS 13 和 14 也可以在“访达”中按住 Control 键点按（或右键点按）PalmDesk，选取“打开”，再在提示中点按“打开”。Apple 从 macOS 15 起取消了这种方式，只能按第 4、5 步在“系统设置”中允许。参见 Apple 支持文章[打开来自未知开发者的 Mac App](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac)。

## 在 Windows 上安装

Windows 安装包没有代码签名，Microsoft Defender SmartScreen 可能会拦截。

1. 双击 `PalmDesk-<版本号>-windows-x64.exe`。如果出现“Windows 已保护你的电脑”，点“更多信息”。
2. 确认应用名称是刚下载的 PalmDesk 安装包、发布者显示为“未知发布者”，然后点“仍要运行”。
   <!-- 截图：SmartScreen“Windows 已保护你的电脑”展开“更多信息”后，显示应用名称、“未知发布者”和“仍要运行”按钮 -->
3. 按安装向导完成安装，之后从“开始”菜单或桌面快捷方式打开 PalmDesk。
   <!-- 截图：PalmDesk 安装向导 -->

- 浏览器下载时也可能提示这类文件不常见或可能有害。确认来自 GitHub Releases 后，可在浏览器的下载列表中选择保留。
- 没有“仍要运行”按钮时，可能是单位的管理策略，或 Windows 11 的“智能应用控制”拦截了未签名的应用。微软说明[智能应用控制会阻止未签名的应用，且无法为单个应用绕过](https://support.microsoft.com/zh-cn/topic/what-is-smart-app-control-285ea03d-fa88-4d56-882e-6698afdb7003)；关闭它会降低系统防护，请自行权衡。
- Windows 不需要下一节的 macOS 权限。被操作的应用和 PalmDesk 需要以相同的权限级别运行，通常两者都不要“以管理员身份运行”。

## 授予 macOS 权限

在 Mac 上查看和操作窗口需要为 PalmDesk 授予两项系统权限：

- **屏幕录制**：捕获你在手机上选中的应用窗口。在“系统设置”中名为“录屏与系统录音”（较早的系统中为“屏幕录制”）；PalmDesk 只捕获窗口画面，不录制音频。
- **辅助功能**：切换桌面、还原窗口，以及发送点击和键盘输入。macOS 27 中名为“无障碍”。

只在手机上阅读会话时不需要这两项权限，可以等到要操作窗口时再授权。

1. 打开 PalmDesk，首页会显示“屏幕录制”和“辅助功能”是否“已授权”。macOS 也可能直接弹出授权提醒，点“打开系统设置”即可。
   <!-- 截图：PalmDesk 首页的权限区域，“屏幕录制”和“辅助功能”均为“未授权”，带“打开设置”按钮 -->
2. 点“屏幕录制”旁的“打开设置”，在“隐私与安全性”>“录屏与系统录音”中打开 PalmDesk 的开关，按提示输入登录密码。列表中没有 PalmDesk 时，点列表下方的“+”，从“应用程序”中选择 PalmDesk。如果 macOS 提示 PalmDesk 需要重新打开才能使用新权限，可以先完成第 3 步，再按第 4 步统一退出重开。
   <!-- 截图：“录屏与系统录音”列表中已打开 PalmDesk -->
3. 点“辅助功能”旁的“打开设置”，在“隐私与安全性”>“辅助功能”（macOS 27 中为“隐私与安全”>“无障碍”）中打开 PalmDesk 的开关。
   <!-- 截图：“辅助功能”列表中已打开 PalmDesk -->
4. 完全退出 PalmDesk：在屏幕顶部的菜单栏选取“PalmDesk”>“退出PalmDesk”，或按 Command-Q。确认程序坞中的 PalmDesk 已不再运行后，再从“应用程序”重新打开。菜单中的“重新启动”只会刷新窗口内容，不能让新权限生效。
   <!-- 截图：菜单栏的“PalmDesk”菜单，突出“退出PalmDesk” -->
5. 重新打开后，两项都应显示“已授权”。

## 用手机完成首次连接

### 在电脑上显示二维码

1. 在 PalmDesk 首页顶部确认显示“服务已连接”。
2. 如果想在手机上阅读 Codex、Claude Code 或 Claude Desktop Code 的本地会话，打开首页的“会话阅读”开关（默认关闭）；只操作窗口可以跳过这一步。
3. 在“手机扫码连接”区域点“显示二维码”。二维码和临时密码每次启动时默认隐藏；二维码旁显示的手机网页地址默认是 `https://palmdesk.abreto.icu/`。
   <!-- 截图：PalmDesk 首页“服务已连接”状态和“手机扫码连接”区域。遮挡二维码、设备代码和临时密码，或截图后立即更新临时密码 -->

二维码包含设备代码和临时密码，作用等同于密码。连接后可以点“隐藏二维码”，不要把二维码、复制出的连接链接或含有它们的截图发给他人或公开分享。如已泄露，在电脑上点临时密码旁的编辑按钮（更新临时密码）：旧二维码随即失效，所有已连接的手机都会断开，之后用新二维码重新连接。

### 用 iPhone 相机扫码（推荐）

1. 打开 iPhone 的“相机”，对准电脑上的二维码，点屏幕上出现的 `palmdesk.abreto.icu` 链接，在默认浏览器（通常是 Safari）中打开。
   <!-- 截图：iPhone 相机识别二维码后显示的 palmdesk.abreto.icu 链接 -->
2. 网页会自动连接这台电脑，不需要手动输入设备代码和密码。
3. 连接成功后，如果电脑开启了“会话阅读”，会进入“阅读”页；否则进入“窗口”页的 Agent 目录。在“窗口”页选择一个窗口后，电脑才开始捕获画面；需要的 Agent 还没打开时，可以点“打开 Agent”。
   <!-- 截图：iPhone Safari 连接成功后的“阅读”页，以及“窗口”页的 Agent 目录 -->

Android 手机可以用系统相机或浏览器自带的扫码功能，在系统浏览器中打开链接。

手机网页会记住连接过的电脑。下次打开 `https://palmdesk.abreto.icu`，点设备代码输入框右侧的箭头，从最近连接的设备中选择后点“连接”；电脑更新临时密码后需要重新扫码。

### 用微信扫码

微信“扫一扫”会在微信内置浏览器中打开同一个网页，可能先显示确认或提示页面，按提示继续即可；微信无法打开时，改用 iPhone 相机扫码。

微信内置浏览器能否远程连接，取决于微信和系统版本。如果页面提示“当前浏览器不支持远程连接，请用系统浏览器打开连接链接”：

1. 点提示旁的复制按钮（复制连接链接）。
2. 打开 Safari，把链接粘贴到地址栏并前往。
   <!-- 截图：微信内置浏览器中“当前浏览器不支持远程连接”的提示和复制连接链接按钮（如该环境会出现） -->

通过微信右上角菜单改用浏览器打开时，连接信息不会带过去：网页读取连接信息后会把它从地址中移除，需要在 Safari 中重新扫码或手动输入。复制出的链接同样包含临时密码，不要转发。

### 其他连接方式

- **网页内扫码**：在手机浏览器中打开 `https://palmdesk.abreto.icu`，点“扫码连接”并允许使用相机；也可以点“选择二维码图片”，从相册识别二维码，用完后删除这张图片。
- **手动输入**：在手机网页的“远程设备代码”中输入电脑上的设备代码，点“连接”，再输入临时密码（在电脑上点眼睛按钮显示）。

## 常见问题

### 连不上

- **电脑或手机显示“服务未连接”**：检查网络后点“重连服务”。
- **手机提示“该设备不在线，请确认电脑已连接服务”**：确认电脑上的 PalmDesk 正在运行并显示“服务已连接”，电脑也没有睡眠。
- **提示“密码错误，请重新输入”**：电脑可能已更新临时密码，旧二维码随之失效。在电脑上重新显示二维码后再扫。
- **电脑上的二维码区域显示“等待连接服务”或“未设置手机网页地址”**：先等电脑连上服务。改过“高级设置”中的连接服务时，手机网页和电脑必须使用同一个服务。
- **手机提示“当前浏览器不支持远程连接”**：改用 Safari，见[用微信扫码](#用微信扫码)。
- **网页扫码提示需要 HTTPS 或无法打开相机**：在 Safari 中允许该网站使用相机，或改用 iPhone 相机扫码。
- **开着代理或 VPN 软件**：可能影响连接，可以暂时关闭后再试。
- **版本**：电脑端请使用 GitHub Releases 中的最新版本；手机网页刷新后即使用服务端当前的版本。

### 权限不生效

- 修改权限后必须完全退出 PalmDesk 再重新打开（“退出PalmDesk”或 Command-Q）。只关闭窗口或使用菜单中的“重新启动”都不够。
- 在两个权限列表中确认 PalmDesk 的开关都已打开。仍不生效时，在列表中选中 PalmDesk，点“−”移除，再点“+”重新添加“应用程序”中的 PalmDesk，打开开关后再次完全退出并重新打开。
- 电脑上只保留“应用程序”中的一份 PalmDesk。启动时提示“PalmDesk 应用身份冲突”时，推出仍挂载的安装盘，删除提示中列出的其他副本，然后重新打开。
- 手机提示“请为 PalmDesk 开启屏幕录制权限并重启应用”或“请为 PalmDesk 开启辅助功能权限”时，在电脑上按[授予 macOS 权限](#授予-macos-权限)处理。
- macOS 之后可能再次询问是否允许 PalmDesk 继续录屏。需要继续远程操作时选择允许；误拒绝后按上文重新打开开关。
- Windows 提示“Windows 不允许控制此窗口”时，让被操作的应用和 PalmDesk 以相同的权限级别运行，通常两者都不要使用管理员身份。

### 同一 Wi-Fi 与移动数据

电脑和手机都先连接 PalmDesk 服务完成认证，然后通过 WebRTC 传输视频和操作，能直连时优先直连。

- **同一 Wi-Fi**：通常可以直连，延迟最低，建议首次试用时使用。访客 Wi-Fi 或开启了“AP 隔离”的路由器会阻止手机和电脑互连。如果 macOS 询问是否允许 PalmDesk 查找本地网络上的设备，请选择允许；误拒绝后，可在“隐私与安全性”>“本地网络”中打开 PalmDesk。
- **手机用 4G/5G，电脑在家庭或公司网络**：通常无法直连，需要经过 TURN 中继转发。默认服务目前使用 Cloudflare 的 TURN 中继，它不在中国网络提供服务，从中国大陆经中继连接时会连到境外节点，延迟可能明显升高，连接也可能不稳定。跨网络和中继连接尚未完成实测。
- 连接后，可以在控制页右上角的“连接设置”中查看延迟。

技术细节见[服务配置](SERVICE_CONFIGURATION.md#turn)。

### 流量

- 选择窗口后才会传输视频。停留在“阅读”页、手机切到其他 App 或锁屏时，窗口视频会暂停。
- 默认的“均衡”最高 2160P、20 fps，码率上限 3000 kbit/s，按上限计算每小时最多约 1.35 GB。
- “省流量”为 1080P、10 fps、1000 kbit/s，每小时最多约 0.45 GB，小字可能变模糊；“高细节”为 2160P、30 fps、8000 kbit/s，每小时最多约 3.6 GB。
- 码率是上限，不是固定用量；实际流量随画面变化和网络状况变化。
- 使用移动数据时建议选择“省流量”：连接前在手机网页的“连接画质”中选择，或连接后在控制页的“连接设置”中切换。选择会保存在当前浏览器中。
  <!-- 截图：手机控制页“连接设置”中的“画质预设”，已选中“省流量” -->
